期刊管理

增删期刊后点"保存到仓库"，系统会在下一次自动运行时完成抓取；新增期刊会自动回溯全部历史题录。

GitHub 令牌

令牌用于把期刊清单、收藏、笔记和日志写回仓库，只保存在您自己的浏览器里，不经过任何第三方。

如何创建一个令牌（约 1 分钟）
  1. 打开 github.com/settings/personal-access-tokens/new（需登录）。
  2. Token name 随意，如 digest-admin；Expiration 建议 90 天或自定义。
  3. Repository access 选 Only select repositories，勾选 3701-lecy-forever。
  4. Permissions → Repository permissions → Contents 设为 Read and write。
  5. 底部 Generate token，复制以 github_pat_ 开头的串，粘贴到下面。

翻译 API

用于"翻译摘要"按钮。Key 只保存在您自己的浏览器里。默认使用智谱 GLM-4-Flash（免费额度，注册即送），也可换成任何 OpenAI 兼容接口。

如何获取免费的智谱 Key（约 2 分钟）
  1. 打开 open.bigmodel.cn，用手机号注册登录。
  2. 右上角头像 → API keys（或直接访问 API keys 页面）。
  3. 点"添加新的 API Key"，复制生成的 Key，粘贴到下面。
